# 📖 Tentang HijauIn

**HijauIn** merupakan platform digital yang mendorong masyarakat untuk menerapkan gaya hidup ramah lingkungan melalui pencatatan aktivitas sehari-hari.

Pengguna dapat mencatat berbagai aksi hijau seperti membawa tumbler, menggunakan transportasi umum, menghemat listrik maupun air, hingga menanam pohon. Setiap aktivitas akan menghasilkan **Eco Score**, **Experience (XP)**, serta meningkatkan **Level** pengguna.

Selain itu, HijauIn menghadirkan **AI Green Assistant** berbasis **Google Gemini AI** yang membantu pengguna memperoleh rekomendasi aktivitas ramah lingkungan, edukasi keberlanjutan, serta menjawab berbagai pertanyaan mengenai lingkungan.

Melalui sistem **Challenge**, **Leaderboard**, dan **Komunitas**, HijauIn berupaya membangun kebiasaan hijau secara berkelanjutan dan menyenangkan.

# 🚀 Instalasi

HijauIn dapat dijalankan menggunakan repository GitHub maupun source code.

## Clone Repository

```bash
git clone https://github.com/mdwkrnwn/HijauIn.git
```

Masuk ke folder project

```bash
cd HijauIn
```

Install dependency

```bash
npm install
```

---

# ⚙️ Environment Variables

Buat file

```text
.env.local
```

Isi dengan konfigurasi berikut

```env
NEXT_PUBLIC_SUPABASE_URL=YOUR_SUPABASE_URL

NEXT_PUBLIC_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY

GOOGLE_GENERATIVE_AI_API_KEY=YOUR_GEMINI_API_KEY
```
